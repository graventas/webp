# Personal Branding Website - Jonathan (Cyber & AI)

Website personal branding interaktif modern yang dirancang khusus untuk mahasiswa **S1 Teknologi Informasi - Telkom University** dengan ketertarikan mendalam pada **Cybersecurity** dan **Artificial Intelligence**.

---

## 🚀 Fitur Unggulan

1. **Foto Profil Terintegrasi**: Menggunakan file foto `fotoprofil.jpg` dengan efek *holographic cyber border*, *scanline animation*, serta *3D tilt effect* interaktif yang merespons pergerakan kursor mouse.
2. **Identitas Kampus Telkom University**: Spotlight khusus kampus Telkom University, Fakultas Informatika / School of Computing, dan Program Studi S1 Teknologi Informasi.
3. **Dual Core Focus (Cyber & AI)**:
   - **Cybersecurity**: Ethical Hacking, Network Defense, OWASP Top 10, Wireshark, Burp Suite, CTF.
   - **Artificial Intelligence**: Machine Learning, Deep Learning, PyTorch, LLM, Computer Vision.
   - **The Synergy**: *AI-Powered Threat Detection* & *Securing AI / LLM Guardrails*.
4. **Interactive Terminal CLI (`>_ CLI`)**:
   - Pengunjung dapat mengetik perintah langsung di dalam browser seperti: `help`, `about`, `edu`, `skills`, `projects`, `contact`, `github`, `linkedin`, `matrix`, `whoami`, `clear`, hingga rahasia `cat flag.txt`.
5. **Interactive Neural Network Matrix Canvas**:
   - Background canvas animasi partikel dan *synaptic connections* yang bereaksi terhadap sentuhan dan kursor mouse.
6. **Skills & Tools Filter Switcher**: Filter dinamis berdasarkan kategori (Cybersecurity, AI/ML, Dev & Infra).
7. **Audio SFX Synthesizer (Web Audio API)**: Efek suara interaktif retro-futuristik (bisa diaktifkan/dinonaktifkan melalui tombol speaker di pojok kanan bawah).
8. **Koneksi LinkedIn, GitHub & Email**: Tombol direct link dan fitur *copy to clipboard* email kampus Telkom University.
